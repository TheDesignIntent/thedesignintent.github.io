# Antonio Latto — portfolio

Static portfolio built from the Behance work at https://www.behance.net/antoniolatto.

All projects are public. There is no password protection on this site.

## Preview locally

```bash
python3 -m http.server 8091
```

Then open http://localhost:8091/

## Publishing

Copy the contents of this folder to a GitHub Pages repository (or any static host) and enable Pages from the main branch. The site is plain HTML, CSS, and images — no build step at deploy time.

Images were resized for the web (longest edge 2000px) from the original Behance downloads.
